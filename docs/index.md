# memcal docs

**Memory + Calendar for AI agents.** Memcal keeps an agent calendar of your life —
events, to-dos, open questions, and durable facts about people, places, and projects —
fed by the streams you already get, with a nightly pass that reads new traffic and
proposes typed updates.

This site holds the hands-on setup guides. The canonical product overview, command
reference, and development workflow live in the
[README](https://github.com/cuuush/memcal/blob/main/README.md) on GitHub.

Start here:

- [Quickstart](quickstart.md) — install memcal, pick a model backend, run the first ingest.
- [Chat sources](sources/index.md) — connect [Slack](sources/slack.md),
  [Telegram](sources/telegram.md), or [Signal](sources/signal.md).
